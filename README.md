# The Lost Sky Pirate — GitHub 使用说明

项目地址：<https://github.com/Cheney099/TheLostSkyPirate>

本仓库由 Cheney 和 Vincent 共同维护。日常同步不需要填写集数、分支名、文件名或 PR 编号，只需要把下面的通用提示词发给 Codex，由 Codex 自动检查当前项目状态和实际改动。

## 拉取最新内容

每次开始工作前，把这句话发给 Codex：

> 帮我安全拉取这个项目在 GitHub 上的最新更新。请自动检查并处理；遇到冲突或不确定的情况再问我，完成后告诉我结果。

Codex 会自动：

- 识别当前仓库和默认分支；
- 检查本地是否有未提交修改；
- 获取 GitHub 最新内容；
- 选择安全的同步方式；
- 保留本地工作；
- 只有遇到冲突或无法判断的取舍时才询问你。

## 上传自己的更新

完成工作后，把这句话发给 Codex：

> 帮我把这个项目目前的本地更新安全上传到 GitHub。请自动检查和整理实际改动，创建或更新合适的 PR；遇到冲突或不确定的情况再问我，完成后告诉我结果和 PR 链接。

Codex 会自动：

- 检查所有本地改动及其关联范围；
- 判断哪些文件属于同一项工作；
- 排除缓存、临时文件、凭证和无关修改；
- 自动选择已有任务分支或创建新分支；
- 验证修改过的 JSON 等结构化文件；
- 创建清晰的提交并推送；
- 自动更新已有 PR，或创建新的 PR；
- 返回改动摘要和 PR 链接。

## 使用原则

- `main` 是受保护的稳定分支，所有更新通过 PR 合入。
- Codex 应根据实际改动自动确定分支名、提交范围和 PR，不要求用户预先填写。
- 如果本地包含多项互不相关的工作，Codex 应当安全拆分，不能全部混进一个 PR。
- 同一个文件被两个人同时修改时，Codex 必须停下来说明冲突，不能直接覆盖任意一方。
- 不上传视频成片、本地渲染、缓存、临时文件、Token、密码或其他敏感内容。
- 仓库是公开的，上传前必须排除隐私信息、客户机密和无权公开的素材。
- 上面的通用提示词不授权 Codex 自动 approve 或 merge；最终审核和合并由 Cheney 或 Vincent 决定。

更完整的多人协作和文件安全规则见 [AGENTS.md](AGENTS.md)。
